Large file handling: Files > 100 MB are streamed in chunks and uploaded via S3 multipart upload, keeping the memory footprint under 10 MB.
Scheduling: EventBridge fires every Sunday 02:00 SGT. Step Functions orchestrates the workflow and handles retries with exponential backoff.
Network: The Glue download job runs in a private subnet and reaches data.gov.sg through the NAT Gateway in the DMZ.
